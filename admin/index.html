    ℹ️ Información

    Bienvenido al CMS

    Esta es una interfaz web simple para gestionar tu contenido Jekyll.

    Ubicaciones de archivos:

    • _pages/ - Páginas estáticas
    • _posts/ - Artículos de blog
    • assets/uploads/ - Imágenes y medios

    Cómo usar:

    1. Edita los archivos Markdown directamente en tu editor de texto
    2. O usa esta interfaz para crear posts nuevos
    3. Guarda los cambios y haz commit a Git
    4. Los cambios se despliegan automáticamente
