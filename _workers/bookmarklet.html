📚 Wishlist Bookmarklet

Agrega productos a tu wishlist desde cualquier página web

Arrastra este botón a tu barra de marcadores:

➕ Add to Wishlist

📖 Instrucciones de Uso

  1. Arrastra el botón "Add to Wishlist" a tu barra de marcadores del navegador
  2. Navega a cualquier página de producto (Amazon, MercadoLibre, etc.)
  3. Haz click en el bookmarklet de tu barra de marcadores
  4. Usa los botones 🎯 para seleccionar elementos:
    • Click en 🎯 junto a "Title"
    • Luego click en el título del producto en la página
    • El texto se copiará automáticamente
    • Repite para imagen, notas, etc.
  5. Edita manualmente cualquier campo si es necesario
  6. Preview: La imagen seleccionada se muestra a 250x250
  7. Guarda con el botón "Save to Wishlist"
💡 Tip: La URL del producto se detecta automáticamente. Los campos son editables, así que siempre puedes ajustar lo que seleccionaste.

🎬 Cómo Funciona el Target 🎯

  1. Click en el botón 🎯 al lado del campo que quieres completar
  2. El popup se colapsa automáticamente a solo una barra de título para no obstruir la página
  3. Los elementos sobre los que pasas el mouse se resaltan con un borde azul
  4. Click en el elemento que quieres capturar:
    • Title/Notes: Copia el texto del elemento
    • Image: Copia la URL de la imagen (src o background)
  5. El popup se expande nuevamente y el campo se completa automáticamente
  6. Presiona ESC en cualquier momento para cancelar el target mode

🖱️ Mover el Popup

  • Arrastra el popup desde la barra de título (zona morada) para moverlo a cualquier posición
  • Funciona tanto cuando el popup está expandido como cuando está colapsado
  • Útil si el popup está tapando algo que necesitas ver
